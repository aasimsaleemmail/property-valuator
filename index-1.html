Formula: Land value = plot size (Marla) × DC rate per Marla. Structure value = covered area (sq ft) × structure rate per sq ft (only counted if you select "Yes" for structure). Combined value = land value + structure value. Stamp duty and TTIP tax are each 1% of the combined value. If a structure exists and its plan is not approved, an additional 2% stamp duty is charged on the combined value. Fixed charges: registration fee Rs. 500, PLRA service charges Rs. 3,600, local commission Rs. 5,500. This is an estimate based on official DC rates and standard charges only — actual government charges can change and may include additional taxes not listed here.
